### exportExcel.py
    读取 zh-CN.json 和 en-US.json，生成可以复制到 国际化导入模板.xlsx 的 xlsx文件
### flatten_json.py
    将json扁平化处理， 如 
        {
            "title":{
                "title1":"标题"
            }
        }   
    处理成： { "title.title1":"标题" }
### lowercase_data.py
    将json的key值全部转换成小写
### sort_json.py
    将两份json的key排列顺序整理成一样
